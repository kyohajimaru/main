Webまわりを整えるとき、最初から大きな制作を考えなくても大丈夫です。

まずは「誰に」「何を届けたいか」「次にどんな行動をしてほしいか」を短い言葉にしてみます。言葉が整うと、ホームページ、SNS、LINEの役割も決めやすくなります。

小さなお店ほど、無理なく続けられる形にすることが大切です。
